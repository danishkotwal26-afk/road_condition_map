# 🛣️ RoadWatch — Road Condition Map

A lightweight, real-time road condition visualizer built with **Leaflet.js** and vanilla JavaScript. Color-coded polylines show road quality across a mapped area, with live auto-refresh from a local JSON data source.

## ✨ Features

- 🗺️ **Interactive map** powered by Leaflet.js
- 🎨 **Color-coded polylines** — Good / Fair / Bad road segments
- 🔍 **Filter panel** — show only the condition type you care about
- 📊 **Live stats bar** — segment counts per condition, clickable to filter
- 🛰️ **3 tile layers** — Street, Satellite (Esri), Dark (CARTO)
- 📋 **Road detail panel** — click any segment for length, coordinates & badge
- ♻️ **Auto-refresh every 30s** — picks up new data without a page reload
- 📍 **Auto-fit bounds** — map centers itself on your actual data, no hardcoding needed

## 🚀 Getting Started

Since this is a purely static app (no build step, no backend), just serve it with any local HTTP server.

### Option 1 — VS Code Live Server
Install the [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer), right-click `index.html` → **Open with Live Server**.

### Option 2 — Python
```bash
python -m http.server 8080
# then open http://localhost:8080
```

### Option 3 — Node.js
```bash
npx live-server
```

> ⚠️ **Do not open `index.html` directly as a `file://` URL.** The `fetch()` call for `roads.json` will be blocked by CORS. Always use a local server.

## 🗂️ Data Format

Road data lives in `data/roads.json`. Each entry is a segment with an array of `[lat, lng]` coordinate pairs and a condition string:

```json
[
  {
    "coords": [[15.884172, 74.525545], [15.884002, 74.526950]],
    "condition": "bad"
  },
  {
    "coords": [[15.879275, 74.525757], [15.881133, 74.531239]],
    "condition": "good"
  }
]
```

**Valid condition values:** `"good"` · `"medium"` · `"bad"`

To add more roads, just append more objects to the array. The map auto-fits to whatever coordinates are in the file.

## 🛠️ Customisation

| What | Where |
|------|-------|
| Change refresh interval | `REFRESH_MS` constant in `app.js` |
| Add a new tile layer | `TILES` object in `app.js` |
| Change colors | CSS variables `--good`, `--medium`, `--bad` in `style.css` |
| Add new condition types | Extend `getColor()` and `conditionLabel()` in `app.js` |
